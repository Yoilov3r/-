# 走进千里江山图

一张可游卷的《千里江山图》实时长卷。原画始终是画面主体，键盘、拖拽、滚轮和触屏摇杆改变的是画中取景，而不是切到另一套三维场景。

## 运行

模块脚本需要通过 HTTP 访问：

```powershell
python -m http.server 4173
```

打开 `http://127.0.0.1:4173/qianli-jiangshan/`。

## 操作

- 鼠标或触屏拖动：游卷
- `W A S D` / 方向键：游卷
- `Shift`：加速游卷
- 滚轮：远近
- `R`：回到入谷起点
- 移动端左下摇杆：连续游卷
- 行旅按钮：进入入谷、松风、山居、远岫

## 素材

- 王希孟《千里江山图》，北宋，故宫博物院藏。
- 原画扫描来自 Wikimedia Commons，公有领域。
- 主画布使用 `7438×1600` 高清连续裁片，确保放大后保留绢纹与细皴。

## 验收

运行本地服务后执行：

```powershell
node .\qianli-jiangshan\scripts\capture.mjs
```

脚本会在真实 Chrome 中验证桌面与移动端布局、交互坐标、原画弹窗、控制台错误和失败请求，并输出截图与 `shots/qa.json`。
