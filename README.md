# 走进千里江山图

把王希孟《千里江山图》重建为可第一人称行走的实时三维画境。山体、河谷、长桥、村舍与松林都在 Three.js 世界中实际建模，远景保留原画扫描作为绢本环景，近景用青绿矿物色、皴线和手绘植被延续长卷语言。

## 在线进入

[https://yoilov3r.github.io/-/](https://yoilov3r.github.io/-/)

## 运行

模块脚本需要通过 HTTP 访问：

```powershell
python -m http.server 4173
```

打开 `http://127.0.0.1:4173/qianli-jiangshan/`；部署到 GitHub Pages 根目录时
打开站点根路径。

## 操作

- `W A S D` / 方向键：贴地行走
- `Shift`：疾行加速
- 桌面鼠标移动：直接环顾；点击画布锁定指针，`Esc` 释放
- 触屏拖动：环顾画境
- 滚轮：调整视域
- `R`：回到入谷起点
- 移动端左下摇杆：连续行走
- 行旅按钮：前往入谷、松风、山居、远岫
- 右上“原画对照”：查看长卷局部与题跋

## 场景结构

- 主地形：多峰窄脊高度场，加入分形起伏、河岸台地与起点缓坡。
- 地表：高度、坡度和日照烘焙为顶点色，再叠加程序化绢色笔触贴图，以石青、石绿、赭石和墨色叠染。
- 水岸：沿曲线河道生成流动水纹着色器。
- 建筑：可行走木桥、桥上亭、桥墩、栏板和村舍；桥头以七米引坡、挡土面和石砌桥台接入河岸。
- 植被：四种程序化松冠笔触组成三层错向冠团，并配独立树干；草簇使用
  三平面交叉笔触和实例化落位，桌面保留 `2200` 个有效草簇。草簇按地形
  法线倾斜、根部埋入地表，并使用不透明 Alpha 裁剪与深度写入。
- 自然落位：以实际可见水面 `15.5` 为统一边界，树木、亭子、村舍与岩石按各自占地范围退到干岸，亭台增加沉入坡地的石基。
- 远景：单圈原画主层、低透明错位副层和程序化绢雾叠加，削弱横向重复与
  环景接缝。

## 素材

- 王希孟《千里江山图》，北宋，故宫博物院藏。
- 原画扫描来自 Wikimedia Commons，公有领域。
- `assets/qianli-world.jpg` 为 `7438×1600` 高清连续裁片。
- `assets/qianli-panorama.jpg` 用于三维远景绢景。

## 验收

运行本地服务后执行：

```powershell
pnpm install
pnpm run qa
```

脚本会在真实 Chrome 中验证桌面与移动端布局、键盘行走、鼠标移动环顾、
滚轮视域、行旅跳转、触屏摇杆、原画弹窗、控制台错误和失败请求，并输出
截图与 `shots/qa.json`。
如本机 Chrome 不在默认位置，可设置 `CHROME_PATH`；如页面地址不同，可设置
`QIANLI_URL`。

验收使用硬断言：全部通过时退出码为 `0`，任一断言失败时退出码为 `1`。
失败详情会写入 `shots/qa.json` 的 `verification` 字段，可直接用于本地验收
或 CI。场景细节审计同时验证松冠层数、笔触变体、草丛实例数量、草地接地、
远景层数、绢雾开关和桌面性能预算。
